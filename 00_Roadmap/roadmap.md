Tesi triennale

Database security in era of AI: studiare come proteggere
l'accesso di agenti LLM a basi di dati attraverso server MCP.

Obiettivo:
Studiare le problematiche di sicurezza dell'accesso a PostgreSQL
da parte di agenti LLM attraverso MCP server e valutare possibili
contromisure tramite un prototipo sperimentale.

Prime attività:
1. Analisi di 3/4 MCP server PostgreSQL
2. Confronto delle loro caratteristiche e meccanismi di sicurezza
3. Creazione di un ambiente LLM + MCP + PostgreSQL
4. Definizione degli scenari di sicurezza
